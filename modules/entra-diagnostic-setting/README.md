# entra-diagnostic-setting

Exports Entra ID audit and sign-in logs to a Log Analytics workspace.

Creates nothing when `log_analytics_workspace_id` is empty, which is the
current state in every environment — the wiring exists, the destination has not
been chosen. Enabling it requires **Security Administrator** on the applying
principal.
