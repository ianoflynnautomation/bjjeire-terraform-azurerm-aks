# cloudflare-tunnel

Cloudflare Tunnel and the DNS records that point at it — the cluster's only
inbound path. The tunnel's remote configuration sends traffic to the Istio
ingress gateway on `:443`; there is no public AKS ingress.

Includes two cleanup shims. An Azure teardown leaves the Cloudflare tunnel
behind, so recreating the same name returns `409 / code 1013`;
`terraform_data.clear_stale_tunnel` removes inactive leftovers while leaving a
healthy tunnel with live connectors alone. `clear_conflicting_dns` does the
same for orphaned records.
