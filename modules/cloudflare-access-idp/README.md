# cloudflare-access-idp

Cloudflare Zero Trust Access, with Entra ID registered as the OIDC identity
provider. Spans both providers: it creates the Entra application and service
principal that back the IdP (including the Microsoft Graph delegated grants),
then the Cloudflare identity provider, application, and policies.

Optionally issues a service token so CI can bypass Access on dev and staging —
forced off in prod.

This is the gate for human traffic; its allow-list is a production
access-control surface. See
[ADR-0004](../../docs/adr/0004-cloudflare-access-replaces-oauth2-proxy.md).
