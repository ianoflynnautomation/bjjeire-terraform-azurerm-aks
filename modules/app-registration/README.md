# app-registration

Generic primitive: one Entra ID application registration plus its service
principal. Everything that varies — scopes, app roles, redirect URIs, optional
claims, required resource access — is an input, so the same module backs the
API, SPA, tests, and oauth2-proxy registrations.

Composed by [`bjjeire-app-registrations`](../bjjeire-app-registrations/) and
called directly from `main.oauth2.tf`.

> Everything below `BEGIN_TF_DOCS` is generated by
> [terraform-docs](https://terraform-docs.io/). Run `pre-commit run terraform_docs`
> (or the command in [AGENTS.md](../../AGENTS.md)) after changing inputs or
> outputs — CI fails when it is stale.
