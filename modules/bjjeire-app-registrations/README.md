# bjjeire-app-registrations

Project-specific composition over [`app-registration`](../app-registration/).
Creates the three registrations that form the application's auth model and
wires the relationships between them:

- **api** — audience, `access_as_user` scope, `Tests.Invoke` app role
- **spa** — redirect URIs, pre-authorized on the API scope (`azuread_application_pre_authorized`)
- **tests** — client credentials, granted `Tests.Invoke` on the API service principal

See [identity.md](../../docs/architecture/identity.md#entra-id-application-registrations).
