# cloudflare-zone

Zone-level Cloudflare configuration: managed WAF rulesets, cache rules,
security headers (CSP, HSTS, Referrer-Policy), and zone settings.

Gated on `manage_zone`. The zone is shared across environments, so only one
environment should own it — the rest leave `cloudflare_manage_zone = false`.
